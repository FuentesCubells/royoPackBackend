# RoyoPack — Backend

API REST del proyecto RoyoPack, desarrollado para **[APBOX](https://apbox.es)**, empresa especializada en soluciones de packaging industrial y e-commerce.

## Stack

- **Node.js** — runtime
- **JavaScript** — ES modules
- **Express** (o equivalente) — enrutado y middleware
- **Railway** — despliegue

## Repo relacionado

Frontend: [`royoFrontend`](https://github.com/FuentesCubells/royoFrontend) — Angular 17

## Desarrollo local

```bash
npm install
node index.js
```

## Despliegue

Desplegado en Railway. Configura las variables de entorno necesarias en el panel de Railway antes del primer deploy.

## Cliente

Desarrollado para [APBOX](https://apbox.es) — soluciones de packaging 360 para empresas industriales, comerciales y e-commerce.
